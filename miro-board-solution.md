STEP 1 — Add your user stories as stickies (non-negotiable)

Create 7 sticky notes, one per story.
Paste exactly these (one story per sticky):
	•	Remove old furniture and fixed fixtures
	•	Inspect and repair walls
	•	Paint walls and ceiling
	•	Install new flooring
	•	Upgrade electrical fixtures
	•	Install curtains or blinds
	•	Deep clean after renovation

👉 All stickies should start near the center, not pre-sorted.

⸻

STEP 2 — Agree on ONE definition of “Value”

Before moving anything, say (or write):

Value = makes the apartment usable, safe, or livable

This prevents arguing later about “nice vs necessary”.

⸻

STEP 3 — Place the foundational prerequisites first

These are not optional choices — they are blocking tasks.

Put these in High Value / High Effort (top right):
	•	Remove old furniture and fixed fixtures
	•	Inspect and repair walls
	•	Install new flooring

Why:
	•	They unlock everything else
	•	High effort, high necessity
	•	They must happen for the renovation to succeed

⚠️ Do NOT put them in “Do it now” just because they’re first in time.
Lean Matrix is value vs effort, not schedule.

⸻

STEP 4 — Place finishing but essential tasks

These go in High Value / Low Effort (top left):
	•	Paint walls and ceiling
	•	Upgrade electrical fixtures

Why:
	•	High perceived value
	•	Comparatively lower effort than flooring or teardown
	•	Clear “quality jump” for the apartment

These are your “Do it now” items.

⸻

STEP 5 — Place completion tasks

These belong in Low Value / Low Effort (bottom left):
	•	Install curtains or blinds
	•	Deep clean after renovation

Why:
	•	They matter, but only after core work
	•	Low complexity
	•	Value is conditional

Label this quadrant clearly as:

Do it if/when there is time

⸻

STEP 6 — Your “Don’t do it” quadrant

For this scenario:
	•	It should remain empty

That is actually a good sign — it means:
	•	All stories are relevant
	•	Nothing is pure waste

An empty “Don’t do it” is acceptable and defensible.

⸻

STEP 7 — Draw dependencies (this is critical)

Now add arrows:
	•	Remove furniture → Inspect & repair walls
	•	Inspect & repair walls → Paint walls
	•	Remove furniture → Install flooring
	•	Install flooring → Paint walls
	•	Paint walls → Electrical fixtures
	•	All core work → Deep clean

This shows you understand sequencing vs prioritisation.

⸻

What your final matrix should communicate

Anyone looking at it should instantly see:
	•	What’s foundational vs finishing
	•	What delivers value early
	•	Why some “low value” items still happen
	•	That effort ≠ order

⸻

One sentence you can say in review

“We used the Lean Matrix to prioritise by value vs effort, then overlaid dependencies to reflect real-world sequencing.”
