## Goal of the Exercise
Simulate a lightweight agile workflow by:
1. Clarifying user stories
2. Estimating **relative effort** using Planning Poker
3. Prioritising work using a **Lean Matrix (Value vs Effort)**

The focus was on **shared understanding and decision-making**, not precise time estimates.

---

## Context
Scenario: Renovating a **35 sqm studio apartment** with help from friends.  
All user stories represent **real, sequential renovation work** with clear dependencies.

---

## User Stories in Scope

1. **Remove Old Furniture and Fixtures**  
   As a renovator, I want to remove all old furniture, light fixtures, and decor from the apartment so that I can start with a blank canvas.

2. **Inspect and Repair Walls**  
   As a renovator, I want to close holes, cracks, and uneven patches so the walls are ready for painting.

3. **Paint the Walls and Ceiling**  
   As a renovator, I want to paint the walls and ceiling in a neutral color to make the apartment brighter and more inviting.

4. **Install New Flooring**  
   As a renovator, I want to replace the old floor with wooden laminate so the apartment feels modern and durable.

5. **Upgrade Electrical Fixtures**  
   As a renovator, I want to replace old switches and install modern lighting so the apartment meets safety standards.

6. **Install Curtains or Blinds**  
   As a renovator, I want to install curtains or blinds to provide privacy and style.

7. **Deep Clean the Apartment**  
   As a renovator, I want to thoroughly clean the apartment after renovation so it is ready for the new resident.

---

## Task 1 — Planning Poker (Effort Estimation)

### Method
- Tool: https://planitpoker.com  
- Scale: Fibonacci (1, 2, 3, 5, 8, 13)  
- Estimators voted **simultaneously**
- Discussion only when estimates diverged
- One **final estimate per story**, uncertainty baked into the number

---

### ✅ Final Effort Estimates (Outcome of Task 1)

| User Story | Story Points |
|-----------|--------------|
| Remove Old Furniture and Fixtures | **5** |
| Inspect and Repair Walls | **8** |
| Paint the Walls and Ceiling | **5** |
| Install New Flooring | **2** |
| Upgrade Electrical Fixtures | **1** |
| Install Curtains or Blinds | **2** |
| Deep Clean the Apartment | **3** |
| **Total** | **26** |

**Notes**
- Wall repairs scored highest due to uncertainty (hidden damage, prep work).
- Furniture removal and painting involved manual effort but were predictable.
- Flooring was rated lower assuming a prepared subfloor and click-laminate system.
- Electrical fixtures were low effort because scope was limited to replacement, not rewiring.

## Task 2 — Lean Matrix Prioritisation

We prioritised the stories using a **Value vs Effort Lean Matrix** in Miro.

**Value** = how much the task makes the apartment usable, safe, or livable  
**Effort** = relative work, risk, and coordination (not time)

---

### Lean Matrix Outcome

#### 🟨 High Value / Low Effort — *Do it now*
- Remove Old Furniture and Fixtures (5)
- Paint the Walls and Ceiling (5)

These tasks quickly unlock progress and visibly improve the space.

---

#### 🟨 High Value / High Effort — *Do it next*
- Inspect and Repair Walls (8)

High impact but uncertain; requires careful sequencing before finishing work.

---

#### 🟦 Low Value / Low Effort — *Do if/when there is time*
- Install New Flooring (2)
- Install Curtains or Blinds (2)
- Deep Clean the Apartment (3)

Finishing or comfort tasks that add value only after core work is done.

---

#### 🟧 Low Value / High Effort — *Don’t do*
- Upgrade Electrical Fixtures (1)

Low effort and limited value in this scenario; must be timed carefully but not a value driver.

---

## Dependencies Identified
- Furniture removal is a prerequisite for **all other work**
- Wall repairs must happen before painting
- Electrical fixtures should be completed before final finishes
- Flooring must be done before deep cleaning
- Cleaning is strictly an end-of-project activity

---

## Key Insights
- Effort ≠ priority: some low-effort tasks are not high value
- Hidden uncertainty (walls) drove higher estimates than visible work
- Lean Matrix helped separate **mandatory sequencing** from **value-based prioritisation**
- Planning Poker worked best as an alignment tool, not a prediction tool

---

## If This Were a Real Project, We Would Start With
1. **Remove Old Furniture and Fixtures**  
2. **Inspect and Repair Walls**

These unblock all downstream work and minimise rework risk.
