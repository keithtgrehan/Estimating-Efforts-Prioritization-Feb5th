## Goal of the Exercise
Simulate a lightweight agile workflow by:
1. Reviewing and clarifying user stories
2. Estimating relative effort using **Planning Poker**
3. Prioritising work using a **Lean Matrix (Value vs Complexity)**

Focus was on shared understanding and decision-making, not “perfect” estimates.

---

## Context
Scenario: Renovating a **35 sqm studio apartment** with help from friends.  
All user stories represent real, sequential renovation work with clear dependencies.

---

## User Stories in Scope
1. Remove Old Furniture and Fixtures  
2. Inspect and Repair Walls  
3. Paint the Walls and Ceiling  
4. Install New Flooring  
5. Upgrade Electrical Fixtures  
6. Install Curtains or Blinds  
7. Deep Clean the Apartment  

---

## Task 1 — Planning Poker (Effort Estimation)

**Method**
- Tool: https://planitpoker.com
- Scale: Fibonacci (1, 2, 3, 5, 8, 13)
- Estimators voted simultaneously
- Discussion only when estimates diverged significantly
- Final numbers logged immediately to avoid rework

### Final Effort Estimates

| User Story | Story Points |
|-----------|--------------|
| Remove Old Furniture and Fixtures | 3 |
| Inspect and Repair Walls | 5 |
| Paint the Walls and Ceiling | 8 |
| Install New Flooring | 13 |
| Upgrade Electrical Fixtures | 8 |
| Install Curtains or Blinds | 2 |
| Deep Clean the Apartment | 1 |

**Notes**
- Flooring scored highest due to precision, effort, and risk of mistakes.
- Electrical work scored high because of safety and compliance uncertainty.
- Cleaning and curtains were low-effort, low-risk tasks.

---

## Task 2 — Lean Matrix Prioritisation

We used a **Value vs Complexity** Lean Matrix in Miro.

**Value** = how much the task enables or unblocks other work  
**Complexity** = effort + risk + dependencies (not just time)

### Lean Matrix Outcome

#### High Value / Low Complexity
- Remove Old Furniture and Fixtures (3)
- Inspect and Repair Walls (5)

These unblock almost all other work and reduce downstream rework.

#### High Value / High Complexity
- Install New Flooring (13)
- Paint the Walls and Ceiling (8)
- Upgrade Electrical Fixtures (8)

Core renovation tasks that deliver most value but carry higher risk and effort.

#### Low Value / Low Complexity
- Install Curtains or Blinds (2)
- Deep Clean the Apartment (1)

Nice-to-have / finishing tasks with minimal impact on earlier stages.

#### Low Value / High Complexity
- None identified in this scenario

---

## Dependencies Identified
- Furniture removal must happen before **everything**
- Wall repairs must be completed before painting
- Electrical work should be done before final paint and fixtures
- Flooring should be installed before deep cleaning
- Cleaning is strictly end-of-project

---

## Key Insights
- Highest effort items are not always first priority
- Early, cheap tasks can unblock the entire system
- Risk (electrical, flooring) matters as much as raw effort
- Lean Matrix made trade-offs visible very quickly

---

## Where We Would Start (Real Project)
1. **Remove Old Furniture and Fixtures**
2. **Inspect and Repair Walls**

These tasks unblock all downstream work and minimise rework risk.

---

## Takeaway
This exercise reinforced that estimation is about **shared understanding**, and prioritisation is about **system flow**, not just speed.
